# Security policy

VaultLite is intended to serve a read-only vault browser on `127.0.0.1` only.

Please report security issues privately through GitHub's **Report a vulnerability** feature rather than opening a public issue. Include the affected version, platform, impact, and reproduction steps. Do not include private vault contents.

Please do not change the default bind address to `0.0.0.0` without adding an explicit, documented opt-in and appropriate access controls.
